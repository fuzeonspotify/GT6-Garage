        Troubleshooting

        How GT6 Garage works

        1. Drop in one file

        Use GLB, OBJ, or glTF. For OBJ/glTF with textures and external buffers, ZIP one model together with its referenced files. Source geometry and original input are retained. Review OBJ orientation and units. Garage uses your installed Blender for FBX and .blend files. Export CAD models as GLB or OBJ first.

        2. Check the important parts

        Rims and tyres are proposed from names, shape, symmetry and materials. Confirm front direction, scale, and wheel positions. Use the part list to correct anything ambiguous. Those corrections travel with the project.

        3. Export deliberately

        Choose Add a new car entry or Replace an existing car, then review the exact destination. Use the resulting combined package as the next baseline to retain previous additions. You can also save an editable project or neutral geometry. A successful binary check is not a gameplay test. Never install an untested package over your only copy.

        Blender is optional

        No bridge is required for normal GLB import. Blender is useful when a source needs manual mesh separation or modelling. The optional GT6 Garage Blender add-on checks your car and prepares its textures before you save a GLB. Install its ZIP from Blender Preferences.

        Your game stays yours.

        The app never launches RPCS3, alters saves, changes emulator settings or transfers files to a console on its own. It runs on loopback only. Use Close Garage to stop the app; closing the browser also lets its idle timeout shut it down.
